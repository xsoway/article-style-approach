# Article Style Approach — 个人文章写作与去 AI 味的思路复现

> 这是一份**方法/思路**仓库，不是代码实现。它把"用个人风格写中文文章、并系统性去 AI 味"这件事，讲成一套可以自己复现的方法论。

这份仓库的核心不是送你一套成品，而是把**这套方法是怎样设计的、每一步为什么这么设计**讲清楚，让你（或任何 Agent）照着方法，在自己的数据上复现出自己的写作 Skill。

## 一、这套思路解决什么问题

绝大多数用大模型写文章的人，卡在两个点上：

1. **写出来一股"AI 味"**——句式整齐、爱总结、爱升华、套话一堆，读着不像人写的。
2. **想纠正但不知道查什么**——凭感觉改，改完还是像；或者干脆放弃，认定"AI 写得就是这样"。

这套思路把问题拆成三件可分别解决的事：

- **机制与数据分离**——把"怎么检查/怎么写"的流程（机制）拆开；把"你爱用的词、你反感的套话"（数据）拆开。想换个人、换种风格，只换数据，不换机制。
- **证据优先**——语料和词表只决定**怎么表达**，不决定**写什么**。文章里的人、事、数字只能来自你这次提供的可核验素材，不补造。
- **去 AI 味分级 + 硬门禁**——把"像不像大模型"做成可定位、可量化、可复现的检查；把"你讨厌的套话"做成硬性发布门禁。

一句话概括这套思路：**把"写作手感"工程化成"可复现的检查"，而不是依赖一句玄学式的"别写得太像 AI"。**

## 二、写作的三步闭环

整个流程是一个 `准备 → 写稿 → 检查` 的闭环，不是"写一稿就完事"：

```text
【准备】从你自己的语料里，统计出"你的风格"（词、句式、连接词）
        → 生成一份"正向风格"候选报告

【写稿】先整理本次可核验的事实 → 读风格报告 → 用你的判断，照着事实写

【检查】对草稿做"去 AI 味"分级定位 + "语气硬门禁"检查
        → 命中处提示、套话处拦截 → 改稿后重跑
```

三个动作的分工要点：

- **准备只读不改**：它读你的语料和词表，每次刷新风格报告。报告是"你过去爱怎么写"的统计，不是"你这次该写什么"的授权。
- **写稿以事实为准**：语料只决定怎么表达，绝不生成你没做过的事；缺证据就写明待验证。
- **检查只检查和拦截**：提示定位你改，套话硬门禁必须改；不自动改写正文。

## 三、去 AI 味的核心方案：分级 + 门禁

去 AI 味不是一句口号，而是两层互补的检查。

### 第一层：分级定位（flavor-lib 思路）

把"像不像大模型"拆成**六个等级**，按嫌疑强度递增打分：

| 级别 | 检查什么 | 处理策略 |
| --- | --- | --- |
| L1 | 普通高频词 | 仅统计密度，不扣分 |
| L2 | AI 偏好词（如"赋能""底层逻辑"） | 每个 +1，限制密度 |
| L3 | 强 AI 短语 | 每个 +2，优先改写 |
| L4 | 强 AI 固定句式 | 每个 +4，建议改 |
| L5 | AI 模板结构（三点式 / 逐节总结 / 结尾升华） | 每个 +8，强制打散 |
| L6 | 组合指纹（多个特征同文共现） | 每个 +10，强改写 |

**关键边界**：这套分级**只报告"文风像不像大模型"，不鉴定"是不是 AI 写的"，也不自动改写**。它给你一个可定位的对象（哪一行、哪一维、多少分），让你知道该改哪里，而不是替你下结论。

产出不是一个"过/不过"，而是三个辅助判断的东西：

- 分级命中（L2–L6 带行号与原文片段）；
- 0–100 痕迹总分 + 区间标签（自然 / 轻微 / 明显 / 强 / 高度模板化 / 典型大模型）；
- 六维指标（词汇 / 短语 / 句式 / 结构 / 重复 / 升华），让你看清**是词像 AI 还是结构像 AI**。

### 第二层：硬门禁（tone-gate 思路）

去 AI 味是**手感问题**，是提示性的；但"你反感的套话"是**你的发布刹车**，应该做成硬性检查：

- `禁用表达`：出现即判失败（把你最反感的套话放这里）；
- `限用词`：出现超过 N 次即失败（比如"链路""边界"最多 2 次）；
- `句式规则`：正则式判定的套话。

两层的分工一句话：**去 AI 味是提示（该不该改你定），语气门禁是硬规则（必须改）**。前者看你写得像不像，后者守你绝不写什么。

## 四、设计原则（长期可参考）

- **统计是候选，不是定论**：风格报告统计文本特征，不证明作者身份；分级命中是写作痕迹提示，不是 AI 作者鉴定。
- **机制与数据分离**：流程不硬编码任何"谁"的词表或禁用表达，只读你自己的数据层。想换风格，换数据即可。
- **证据优先**：脚本只提取和定位；文章由你根据本次可核验素材写成。
- **一软一硬**：去 AI 味是提示，语气门禁是唯一硬性发布检查。
